# 02 — status 与部分失败语义

**构建内容：** 用户不联网即可查看各 Pin 的当前版本与上次更新的失败项；单个 Pin 更新失败时，其余 Pin 的结果被保留，锁文件始终可构建，而 CI 不会静默通过。

**被以下阻塞：** 01

## 验收标准

- [x] `status` 报告各 Pin 的当前版本与上次更新失败项，不发起网络请求
- [x] 单个 Pin 失败时，其条目在 Pins File 中保持上一轮内容不变——不删除、不标记
- [x] 同一轮中成功的 Pin 正常写入
- [x] 有失败时进程以非零码退出；全部成功时退出码为 0
- [x] stderr 摘要醒目列出失败项
- [x] 哈希解析失败时错误包含完整原始构建输出，不猜测哈希值
- [x] 经 CLI seam 的测试覆盖：部分失败下的条目保留、退出码、无 `got:` 行时的完整输出
